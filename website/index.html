Simple flow

Start with a group. Add the lists you actually use.

PesaListas keeps the structure lightweight: create a shared space, choose the list type, then add the details that matter for that list — deadlines for chores, ingredients for recipes, votes for ideas, or bought status for shopping.

  1. 01

    Create or join a group

    Use one group for your home or several for different shared spaces.

  2. 02

    Pick the right list type

    Tasks, chores, recipes, shopping, meals, movies, ideas, activities, or generic lists.

  3. 03

    Plan together

    Complete, vote, cook, buy, archive, and keep shared information tidy.
